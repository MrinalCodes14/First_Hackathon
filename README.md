CivicDrishti is a web-based civic issue reporting platform designed to help citizens report and view problems in their local area.

Project Status --> The project is currently a frontend-only prototype. It is built using HTML, CSS and JavaScript, without a backend or database yet.

How It Works -->
Users can report their issue under Report an issue option, there they need to choose issue category, describe about it and add an image related to it.
The user that can pin the location where the issue is located so that our team can check it and fix it.
The map displays reported civic issues using markers.

Live Issues Map --> 
We also have a live map that provides a map-based view of civic issues, but currently it is a demo type map. We are planning to use the Leaflet - an open source 
Java Script Library for interactive maps.

Issues can be represented through categories such as -->
1) Potholes
2) Garbage
3) Streetlights
4) Water
5) Roads
6) Other
7) User Account

JavaScript currently handles -->
1) Button click events
2) Alerts
3) Category selection
4) Issue selection
5) Map marker interaction
6) Map zooming
7) Location detection
8) Navigation active states
9) Basic UI interactions

The project currently contains Login and Sign Up pages, but account information is not permanently stored because there is no backend or database yet.

Some actions currently display placeholder messages because the backend has not been implemented yet.
